# Final_project_Den-Tany
## Шаблон тестирования на python
### Шаги
1. Клонировать git репозиторий https://github.com/Den-Tany/Final_project_Den-Tany.git
2. Установить зависимости.
3. Запустить тест.
### Стек - 
- pytest
- selenium
- requests
- sqlalchemy
- allure
- config

### Структура
- ./test - _папка с тестами_
- ./page - _описание страниц_
- ./api - _хелперы по работе с API_
- ./data_ui - _данные для тестирования ui_
- ./data_api - _данные для тестирования api_
